# Hivecom TM

Trackmania maps & records stored by Xaseco, the Trackmania Forever server plugin system
with custom front-end including map / player statistics, hunting suggestions and
advanced filtering options. 

At this point, we have over 500 maps and over 40 players who have competed on
them.

## Front-end

The entire front-end is implemented using [Pantry](github.com/dolanske/pantry)
which is our home-grown web framework developed by dolanske which runs on vue's
reactivity system. The styling is done with SCSS.

![Map list](/screenshots/maps.png)

All this data can be used in interesting ways. For people interested in beating
as many records as possible, it is not easier to find out where they can make
some quick gains.
